    Security model

    What this demo actually enforces.

    Hybrid key agreement. ML-KEM-768 (FIPS 203) plus P-256 ECDH, combined with HKDF-SHA256.

    Authenticated framing. The full 21-byte header — type, file index, chunk index, and IV — is AES-256-GCM AAD.

    Chunk-level resume. The receiver exposes a serializable bitmap; the sender re-reads only missing byte ranges.

    No server storage. The relay carries SDP/ICE and room membership, not file bytes.

    Local-firstThe simulated mode is labeled and never contacts a relay.
